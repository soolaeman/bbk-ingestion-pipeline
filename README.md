# ⚙️ BBKitchen Ingestion Pipeline (Scrapers & ETL)

> **Python Telegram Scrapers (RK, SK, KG), Media OCR & Competitor Price Intelligence.**

---

## 🛠️ Tech Stack & Engineering
- **Runtime:** Python 3.10+, Telethon (Telegram MTProto API), Google Drive API, Pillow
- **Pipeline:** Channel Scraper ➔ Price & SKU Parser ➔ Media Uploader ➔ Sheets Normalizer

---

## 🚀 Getting Started
```bash
# Install dependencies
pip install -r requirements.txt

# Run main pipeline
python main.py
```
